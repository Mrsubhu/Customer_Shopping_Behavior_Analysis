# 🛍️ Customer Shopping Behavior Analysis

### Data Analytics Project | Python • PostgreSQL • Power BI

## 📌 Project Overview

This project analyzes customer shopping behavior to understand purchasing patterns, spending trends, product preferences, discount usage, customer loyalty, and subscription behavior.

Using **Python, PostgreSQL, and Power BI**, the project follows an end-to-end data analytics workflow, from data cleaning and feature engineering to SQL-based business analysis and interactive dashboard reporting.

The goal is to transform raw shopping data into meaningful business insights that can support better marketing strategies, customer retention, and data-driven decision-making.

## 🎯 Project Objectives

- Analyze customer spending patterns across different demographics.
- Compare revenue generated by male and female customers.
- Identify top-rated and frequently purchased products.
- Evaluate discount usage and discount-dependent products.
- Compare subscribers and non-subscribers.
- Segment customers into New, Returning, and Loyal groups.
- Examine purchasing behavior across age groups.
- Develop business recommendations based on the analysis.

## 📂 Dataset Overview

The dataset contains **3,900 purchase records and 18 columns** describing customer demographics, product details, and shopping behavior.

| Dataset Details | Description |
|---|---|
| Total Records | 3,900 |
| Total Columns | 18 |
| Missing Values | 37 in Review Rating |
| Customer Data | Age, Gender, Location, Subscription Status |
| Purchase Data | Item, Category, Purchase Amount, Season |
| Shopping Data | Discounts, Purchase History, Ratings, Shipping Type |

## 🔄 Project Workflow

### 1. Data Cleaning & Preparation — Python

- Loaded and explored the dataset using Pandas.
- Checked missing values and dataset structure.
- Imputed missing review ratings using the median rating of each product category.
- Standardized column names using `snake_case`.
- Created an `age_group` feature.
- Derived `purchase_frequency_days`.
- Checked redundant columns and removed `promo_code_used`.
- Loaded the cleaned data into PostgreSQL for further analysis.

### 2. Business Analysis — PostgreSQL

SQL queries were used to investigate key business questions:

1. Revenue by gender.
2. High-spending customers who used discounts.
3. Top 5 products by average review rating.
4. Average purchase amount by shipping type.
5. Subscribers vs. non-subscribers.
6. Products with the highest percentage of discounted purchases.
7. Customer segmentation based on purchase history.
8. Top 3 products within each category.
9. Relationship between repeat purchases and subscriptions.
10. Revenue contribution by age group.

### 3. Dashboard & Visualization — Power BI

An interactive Power BI dashboard was developed to present shopping behavior and business analysis visually.

The dashboard is intended to support exploration of customer spending, product performance, discount patterns, subscription behavior, and customer segments.

## 💡 Business Recommendations

Based on the analysis objectives, the project proposes the following actions:

- **Increase Subscriptions:** Promote exclusive benefits for subscribers.
- **Improve Customer Loyalty:** Reward repeat customers with loyalty programs.
- **Optimize Discount Strategy:** Balance promotional sales with profit margins.
- **Promote Popular Products:** Highlight top-rated and best-selling products.
- **Targeted Marketing:** Focus campaigns on high-revenue age groups and relevant customer segments.
